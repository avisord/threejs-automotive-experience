# autoxd

A car showroom in the browser, built with three.js: orbit a car in one of nine garages, repaint and
re-material its parts, upload your own model, switch its lights on, and export photos and MP4 videos.

**Live:** https://autoxd.vercel.app

## Run it

```sh
pnpm install
pnpm dev      # http://localhost:3000/garage.html
pnpm build    # type-check and build to dist/
```

## Pages

- `/` — home page
- `/garage.html` — the showroom
- `/credits.html` — model, texture and library credits
- `/balls/` — the ball pit, an earlier playground
